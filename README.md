# Fuzzy Time Series Forecasting

A from-scratch implementation of univariate and multivariate Fuzzy Time Series (FTS) models applied to two datasets: the Mackey-Glass chaotic time series and a real-world specimens dataset. Both First-Order (FOFTS) and High-Order (HOFTS) models are implemented and compared.

---

## Overview

Fuzzy Time Series (FTS) forecasting, introduced by Song & Chissom (1993), converts a numerical series into a sequence of fuzzy linguistic labels, learns Fuzzy Logical Relationship Groups (FLRGs), and uses centroid defuzzification to produce crisp forecasts. This project extends the classical univariate approach to a multivariate setting, using a secondary variable (TOTAL SPECIMENS) as an auxiliary input alongside the primary target.

Fuzzy C-Means (FCM) clustering replaces uniform partitioning for data-driven determination of fuzzy set boundaries, and occurrence-weighted centroid defuzzification is used for improved accuracy over simple majority-vote decoding.

## Methodology

### Step 1 — Universe of Discourse
The universe is extended 20% beyond the training data range in both directions to accommodate test-set values outside the training bounds:

```
U_min = y_min − 0.2 × (y_max − y_min)
U_max = y_max + 0.2 × (y_max − y_min)
```

### Step 2 — Phase-Space Embedding
Each series is embedded into a delay-coordinate phase space with lag `τ = 17` and embedding dimension `m = 3`, producing an `(N, 3)` matrix used for FCM clustering:

```
X[i] = [x(i), x(i + τ), x(i + 2τ)]
```

This captures the local attractor geometry of the time series before partitioning.

### Step 3 — FCM Clustering
Fuzzy C-Means is run on the phase-space matrix to find `c` cluster centres. The first coordinate of each centre (the zero-lag value) is extracted and sorted to give the fuzzy set peaks.

```python
cntr, u, *_ = fuzz.cluster.cmeans(X.T, c=c, m=2.0, error=0.005, maxiter=1000)
centers = np.sort(cntr[:, 0])
```

### Step 4 — Triangular Fuzzy Sets
A triangular fuzzy set is constructed for each cluster centre. Set boundaries are placed at the midpoints between adjacent centres; the leftmost and rightmost sets extend to `U_min` and `U_max` respectively.

```
A_i = (centers[i-1], centers[i], centers[i+1])   # interior sets
A_1 = (U_min,        centers[0], centers[1])      # first set
A_c = (centers[-2],  centers[-1], U_max)          # last set
```

### Step 5 — Fuzzification
Each observation is assigned to the fuzzy set for which its triangular membership degree is highest:

```python
def triangular_mf(x, a, b, c):
    if x <= a or x >= c: return 0.0
    return (x - a)/(b - a) if x <= b else (c - x)/(c - b)
```

### Step 6 — FLRG Construction

**First-Order (FOFTS):**
Rules of the form `A_i → A_j` are built from consecutive label pairs. Occurrences are counted to give weighted FLRGs.

**High-Order (HOFTS, order = 2):**
Rules of the form `(A_i, A_j) → A_k` are built from windows of length `order + 1`.

**Multivariate extension:**
The LHS key includes labels from both the primary and auxiliary series:

```
(A_i_primary, A_j_auxiliary) → A_k_primary          # first-order
(A_i, A_j, A_k, A_l) → A_m                          # high-order, order=2
```

### Step 7 — Defuzzification
The forecast is the occurrence-weighted centroid of the consequent fuzzy sets:

```
ŷ = Σ_k (count_k × center_k) / Σ_k count_k
```

If no matching rule exists, a fallback partial-match strategy merges rules sharing the same primary LHS label.

### Step 8 — Evaluation Metrics

| Metric | Description |
|---|---|
| MSE | Mean squared error |
| RMSE | Root mean squared error |
| MAE | Mean absolute error |
| MAPE | Mean absolute percentage error |
| R² | Coefficient of determination |
| Accuracy | 100 − MAPE |

## Key Design Choices

**Why phase-space embedding before clustering?**
Embedding the scalar series into a delay-coordinate space (lag τ = 17) exposes the local dynamics of the attractor, so FCM finds clusters that reflect the geometry of the time series rather than just the marginal distribution of values.

**Why FCM instead of uniform partitioning?**
Uniform intervals place the same resolution everywhere, wasting partitions in sparse regions and under-resolving dense ones. FCM partitions adapt to the data distribution, concentrating fuzzy sets where the series spends most of its time.

**Why weighted centroid defuzzification?**
Counting rule occurrences during training produces a weighted average of consequent centres at inference time, giving more probable transitions greater influence — a simple frequency-based weighting without explicit probability estimation.

**Why a multivariate LHS?**
Including `TOTAL SPECIMENS` as a co-variate in the rule antecedent allows the model to condition on context beyond the primary series alone, capturing cross-variable dependencies that a univariate FTS would miss.
